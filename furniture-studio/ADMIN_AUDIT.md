# Аудит административной панели

## Реально найденные маршруты
- `/admin`
- `/admin/works`
- `/admin/works/new`
- `/admin/works/[id]`
- `/admin/categories`
- `/admin/home`
- `/admin/about`
- `/admin/contacts`
- `/admin/contacts/[id]`
- `/admin/settings`
- `/admin/login`

## Основные существующие потоки, сохранённые в этой версии
- Supabase Auth + middleware + второй guard в dashboard layout.
- CRUD работ, категорий, заявок и способов связи.
- Редактирование секций главной и страницы «О мастерской» через `home_sections`.
- Настройки сайта и SEO через `site_settings`.
- Динамическое меню через `site_menu_items`.
- Загрузка изображений в Storage `works` и `site`.
- Единый редактор изображения для форм, где он уже использован.

## Что переработано в UX/UI
- Постоянный desktop sidebar с активным разделом и логическими группами.
- Мобильный top bar + drawer вместо постоянного sidebar.
- «Работы»: поиск, фильтры, desktop table, mobile cards.
- «Работы»: редактор разбит на секции; публикация вынесена в боковую панель; sticky save bar; предупреждение о несохранённых изменениях.
- «Категории»: компактные cards/list вместо длинной вертикальной формы.
- «Заявки»: inbox-фильтры по статусу, desktop table, mobile cards, ограниченный preview и отдельный просмотр полного сообщения.
- «Главная»: accordion-секции вместо одной длинной страницы.
- «Настройки»: accordion-группы.
- Единое модальное подтверждение удаления.
- Общие loading / empty / error / focus / disabled состояния.

## Намеренно не менялось
- Публичная часть сайта.
- Схема существующих сущностей и названия существующих полей.
- API / Server Actions, кроме UX-обвязки и точечных улучшений ошибок.
- Авторизация и существующие URL.

## Миграции
`0001_init.sql` — базовая миграция. Для уже существующей базы повторно не запускать.
`0002_redesign_fields.sql`, `0003_ensure_menu_defaults.sql`, `0004_sync_schema.sql` — исторические/idempotent миграции текущего проекта. Не запускать базовую `0001` повторно. Перед SQL-изменениями сверять фактическую схему базы.
